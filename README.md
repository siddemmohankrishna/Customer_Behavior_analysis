# 📊 Customer Shopping Behavior Analysis (SQL + Python + Power BI)

## 🔎 Project Summary

This end-to-end Data Analyst project focuses on analyzing customer shopping behavior to uncover meaningful insights that support business decision-making. The project uses Python for data cleaning, SQL for analysis, and Power BI for interactive dashboard visualization.

The dataset contains approximately **3,900 customer purchases with 18 features per transaction**, including demographics, product categories, ratings, discounts, and subscription details. 

---

## 🎯 Business Problem

Retail businesses need to understand:

* Who are the most valuable customers?
* Which products generate the highest revenue?
* How discounts and subscriptions affect spending?
* Which customer segments drive business growth?

This project answers these questions using data-driven analysis.

## 🔄 Project Workflow

## 📊 Key Insights & Findings

### 💰 Revenue Analysis

* Male customers contribute ~68% of total revenue
* Female customers contribute ~32% of total revenue

### 👥 Customer Segmentation

* Loyal Customers: 80%
* Returning Customers: 18%
* New Customers: 2%

This indicates a strong retention base but low new customer acquisition. 

### 🛍️ Category Performance

* Clothing is the top revenue-generating category (~$100K)
* Accessories and Footwear follow as key contributors

### ⭐ Product Insights

* Top-rated products: Gloves, Sandals, Boots
* Accessories and footwear dominate customer favorites

### 🎟️ Subscription & Discount Behavior

* 27% customers are subscribers
* 73% are non-subscribers
* Discount users tend to spend above average

These trends highlight an opportunity for targeted discount and subscription strategies.
